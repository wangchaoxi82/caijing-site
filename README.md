# 财经快讯站

一个简洁的财经行情页：当天热门财经新闻、A股指数与涨幅榜、美股指数与热门个股。手机和电脑都能看，涨跌按中国习惯显示（红涨绿跌）。

## 运行

```bash
node app.js
```

默认监听 `0.0.0.0:3000`，端口可用环境变量 `PORT` 指定（部署平台一般会自动注入 `PORT`）。

零依赖，不需要 `npm install`，要求 Node.js 18 以上。

## 数据来源（全部免费公开接口，无需 Key）

| 栏目 | 来源 |
| --- | --- |
| A股指数、涨幅榜 | 新浪财经公开行情接口 |
| 美股指数、热门个股 | Yahoo Finance 公开 chart 接口 |
| 财经新闻 | 新浪财经滚动新闻（失败时自动改用 Google 新闻 RSS） |

服务端缓存 5 分钟。任一来源失败时，对应栏目显示“暂无数据”，不会编造数字或标题。

## 部署到 Altare

在 Altare 控制台新建应用，选择从 GitHub 仓库导入，填本仓库地址即可。启动命令 `node app.js`，端口使用平台注入的 `PORT`。
